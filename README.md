# Foodplanner

A personal weekly meal-planning app: answer a short intake form, get a 7-day meal plan (high-protein, calorie-controlled, Sainsbury's ingredients) generated by Claude, then review recipes and an aisle-grouped shopping list.

See **[`PROJECT.md`](./PROJECT.md)** for the full product spec/vision, and **[`DECISIONS.md`](./DECISIONS.md)** for the architecture decisions and reasoning behind them. This file is just the dev-facing quickstart.

## Stack

- **Next.js** (App Router, TypeScript) + **Tailwind CSS**, deployed on **Vercel** - the only platform this app needs.
- **Vercel Postgres** (Neon-backed) in production, via Drizzle ORM (`drizzle-orm/neon-http`, `@neondatabase/serverless`). Local dev/tests run against an embedded **PGlite** instance instead - zero setup, no Docker, no account needed.
- **Claude API** (`@anthropic-ai/sdk`) for weekly plan generation, called server-side via a forced tool-use call, validated with Zod.
- **Unsplash API** for recipe photos, with a local SVG-illustration fallback when no key is configured.
- Single shared-password auth gate (`APP_PASSWORD`) - this is a one-household personal app, not multi-user.

## Local development

```bash
npm install
cp .env.example .env   # fill in APP_PASSWORD at minimum; see below
npm run dev
```

Open http://localhost:3000 and log in with whatever you set `APP_PASSWORD` to.

No `DATABASE_URL` is needed locally - the DB client falls back to an embedded PGlite database at `./local-pgdata/` automatically (see `src/lib/db/client.ts`). Run migrations against it once before first use:

```bash
npm run db:migrate
```

To actually generate a plan you'll need a real `ANTHROPIC_API_KEY` in `.env` (see [console.anthropic.com](https://console.anthropic.com/)). Without one, the intake form's "Generate my week" call will fail with a clear error rather than silently doing nothing. `UNSPLASH_ACCESS_KEY` is optional - recipes fall back to local category illustrations without it.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Local dev server (Turbopack) |
| `npm run build` / `npm run start` | Production build / serve |
| `npm run lint` | ESLint |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | Unit tests (Vitest) |
| `npm run test:e2e` | End-to-end smoke test (Playwright) - builds and serves the app itself, generation is mocked (`MOCK_GENERATION=1`) so no live API key is needed |
| `npm run db:generate` | Generate a new SQL migration from `src/lib/db/schema.ts` after a schema change |
| `npm run db:migrate` | Apply migrations - targets PGlite locally, or `DATABASE_URL` if set |
| `npm run db:studio` | Drizzle Studio (DB browser) |
